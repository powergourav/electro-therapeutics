# Per-page PDFs

Each file here is a single page extracted from `../b28140175.pdf`.

- Files are named `page-NNN.pdf`, where `NNN` is the scan/page number in the
  full PDF, zero-padded to three digits (`page-001.pdf` … `page-278.pdf`).
- The numbering follows the **scan order**, which includes the cover, blank
  leaves and front matter. It does **not** match the book's own printed page
  numbers. For example, the printed text body starts several scans in.
- GitHub can preview each PDF in the browser, so you can open any page directly
  from the file list.

These were generated from the full PDF with `pypdf` (one page per file,
no re-compression, so image quality is identical to the source).
